# Full-site build

The MaxDock rebuild is now being delivered as one coordinated full-site implementation rather than page-by-page releases.

## Included

- role-based application shell
- account recovery
- Dock Board
- My Appointments
- five-step Request Dock Appointment workflow
- Operations Queue
- wall display
- Reports
- Settings
- Users
- Data Integration
- QR check-in
- responsive desktop, tablet and mobile layouts

## Release control

- development branch: `feat/full-site-build`
- full-site preview before merge
- no automatic merge to `main`
- PR #8 remains as the Stage 2 reference point
