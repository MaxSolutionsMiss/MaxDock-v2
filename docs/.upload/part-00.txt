/* ==========================================================================
   MaxDock design system — v2

   WHO THIS IS FOR
   Shipping and receiving crew running their day. Often standing, often on a
   phone or iPad on the floor, glancing at it dozens of times a shift.
   Readability beats elegance every time. Nothing decorative.

   WHAT CHANGED FROM v1
   1. Docks are COLUMNS, time is ROWS. Adding doors narrows the columns
      instead of pushing the page taller. 10-15 doors must fit with no
      vertical scrolling.
   2. Rows divide the available height (1fr), so slots are as tall as the
      screen allows and can carry three lines instead of one.
   3. Text size is a user control: normal / large / larger. One attribute on
      <html> rescales the entire interface, because every size is a token.
   4. Real brand colours from the supplied logo.

   BUILD RULES — the contract
   One stylesheet, ever. No !important. No MutationObservers for layout.
   Every script declared in the HTML. One component per job.
   ========================================================================== */
